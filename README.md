# Landscape explorer

This project continues in [Landscape signatures in 3D](https://github.com/rashiedomar/landscape-explorer-3d), covering Angkor, Srei Santhor, Sukhothai and Prambanan.

**[Open the dashboard](https://rashiedomar.github.io/landscape-explorer-3d/)**

Explore seasonal satellite imagery, open water, vegetation change, land cover, 3D terrain, modelled drainage and OpenStreetMap temple and heritage records. The dashboard includes guided tours, source information and reading notes.

The [original dashboard address](https://rashiedomar.github.io/angkor-landscape-explorer/) forwards to the current explorer. Earlier source files and project history remain in this repository.

The assessment is exploratory; mapped patterns and terrain models require further verification before archaeological or agricultural functions can be established.
