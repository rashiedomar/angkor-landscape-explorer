# Angkor landscape explorer

An interactive map exploring water, agricultural landscapes and terrain across the Angkor region, Cambodia.

**[Open the dashboard](https://rashiedomar.github.io/angkor-landscape-explorer/)**

Explore seasonal satellite imagery, water and vegetation changes, land cover, elevation and modelled field outlines. Each layer includes its data source, observation period, methods and interpretation limits. Research notes connect the mapping to published work on Angkor's wider landscape.

Data sources include Copernicus Sentinel-2 and DEM, ESA WorldCover, JRC Global Surface Water and Fields of the World. Observation periods vary by layer and are identified in the dashboard.

The project supports an exploratory remote-sensing assessment. Mapped patterns require further verification before archaeological or agricultural functions can be established.
